**Object Detection Using YOLO**

This project demonstrates object detection in images using YOLO (You Only Look Once), a deep learning model. The system identifies objects and their locations using bounding boxes and labels.

**Tools & Technologies:** Python, OpenCV, YOLO, Jupyter Notebook

**Learning Outcomes:**

Gained basic knowledge of YOLO and object detection

Understood how deep learning models analyze images
